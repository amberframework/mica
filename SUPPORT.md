# Getting help with Mica

- **How do I ...?** Start with the guides: [Regex](docs/regex.md),
  [Inflate](docs/compression.md), [XML](docs/xml.md), and
  [adding a format](docs/ADDING_A_FORMAT.md).
- **A pattern Mica refuses.** See
  [Excluded constructs](docs/regex.md#excluded-constructs) for the rewrite.
- **Something parses wrong or runs slow.**
  [Open a bug report](https://github.com/amberframework/mica/issues/new/choose)
  with the smallest input that shows it.
- **A way past a limit, budget or deadline.** Report it privately: see
  [SECURITY.md](SECURITY.md).
- **Amber questions.** [amberframework.org](https://amberframework.org).
- **Paid help.** [AgentC Consulting](https://agentc.consulting) builds and
  maintains Mica and Amber: agent_c@agentc.consulting.
